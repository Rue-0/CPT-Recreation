CPT Recreation

A simple Continuous Performance Test to practice sustained attention and response control.

How to play: Select Start Test. Press Space only when X appears. Do not press for any other letter. Each letter is visible for 0.8 seconds, followed by a 0.7-second blank screen. There are 20 letters.
